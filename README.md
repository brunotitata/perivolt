# PeriVolt

Protótipo em desenvolvimento. Este repositório contém inicialmente infraestrutura administrativa; fontes do produto ainda não foram importadas.

O dashboard Next.js é separado do monitor nativo C++/Qt. Não há instalador, compatibilidade de hardware certificada nem binários publicados.

Licença do projeto e copyright ainda dependem de decisão explícita do titular. MIT é apenas proposta; este bootstrap não aprova nem importa essa proposta.

Veja CONTRIBUTING.md e docs/DELIVERY.md para verificações e gates de entrega.
